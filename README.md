# HWhelper 3.1.0 — Zarxs

Самостоятельный клиентский мод для **Minecraft 1.21.11 / Fabric / Java 21 / Windows 10–11 (64 бита)**. Telegram, чтение музыки, обложки и синхронные строки работают внутри JVM Minecraft. EXE, Python, фоновый сервер и расширение браузера не требуются. Встроены библиотеки для x64 и ARM64; native-проверки проведены на x64, ARM64 отдельно не проверялся.

## Проверка исходного кода

Публичный репозиторий: [github.com/ZZarxs/HWhelper](https://github.com/ZZarxs/HWhelper). Ссылка также указана в описании мода и полях Homepage / Sources его метаданных Fabric.

Код находится в `src/main/java`, ресурсы — в `src/main/resources`, проверки — в `src/regression`. Инструкция самостоятельной сборки и происхождение нативных библиотек приведены ниже. Для готовых файлов в релизе опубликованы SHA-256.

## Установка

1. Закройте Minecraft. Остановите старый мост через его значок в трее.
2. Удалите из `mods` предыдущий HWhelper / HWMineHelper / mines_hud и отдельный golden-spawner-overlay. Поместите **HWhelper-3.1.0.jar** в `mods`; Fabric API должен быть установлен.
3. Запустите Minecraft. **M → Связь → ПКМ по Telegram → Настроить Telegram**.
4. При первом подключении введите собственные **API ID** и **API Hash** с https://my.telegram.org/apps, затем «Подключить». Это данные приложения Telegram, а не токен бота. Кнопка получения API-данных находится на этом же экране.
5. Войдите по QR-коду (Telegram на телефоне → Устройства → Подключить устройство) либо по номеру, коду Telegram и паролю двухэтапной проверки, если он включён. Поддерживается также подтверждение email, если его запрашивает Telegram.

После входа авторизация сохраняется на этом компьютере и автоматически восстанавливается при запуске. Повторно вводить данные каждый раз не нужно. ЛКМ по модулю Telegram подключает/отключает службу. Отключение сохраняет сессию; «Выйти из аккаунта HWhelper» завершает только сессию этого мода.

Бот остаётся **@liteeventbot**, команда — **«Снимок шахт»**. Мод читает входящие текстовые ответы только этого бота. Запросы идут не чаще раза в пять секунд, одновременно ожидается один ответ; предусмотрены таймаут и пауза при FloodWait. Даты исходных/отредактированных сообщений сохраняются, поэтому повторное чтение одного ответа не запускает таймеры заново.

## Быстрое переключение анархий

**G** открывает компактный выбор анархии. **PageUp** — предыдущая, **PageDown** — следующая анархия; горячие клавиши работают во время игры и не срабатывают при вводе в чате или в чужих меню. Клавиши переназначаются в управлении Minecraft, категория HWhelper.

В выборе сервера: ЛКМ по карточке — перейти, ПКМ — добавить/удалить избранное. Поиск понимает номер, `/an7` и название группы. Можно оставить только избранные, чтобы, например, переключаться по кругу между 2, 4 и 7. Enter переводит на сервер, если поиск оставил ровно одну карточку. На маленьком экране список разбивается на страницы.

**M → Связь → ПКМ по «Быстрый переход»**: включение модуля, выбор СолоЛайт 1–9 / ДуоЛайт 10–19 / ТриоЛайт 20–29 / КланЛайт 30–36, только избранные, обход по кругу, уведомления, пауза между командами 800–5000 мс (по умолчанию 1200 мс) и кнопка переназначения клавиш.

Мод отправляет обычную серверную команду `/anN` только после нажатия клавиши или карточки. Фоновый автоматический перебор, повторная отправка и управление контейнером не используются. Сервер должен поддерживать эти команды, как в приложенной демонстрации HollyWorld. Условия сервера (очередь, заполненность, запрет перехода) продолжают действовать. Подключение подтверждается названием анархии в боковой панели; если подтверждение не получено за восемь секунд, выводится соответствующее уведомление. Повторный выбор текущего сервера не отправляет команду.

Переходы не зависят от Telegram и работают при выключенном HUD шахт. Legacy-серверы «Лайт (1.20)» не включены в список: их отдельная нумерация не смешивается с командами `/anN`. Мини-карта из видео не добавлялась.

## Музыка

Включите Dynamic Island или World Lyrics и запустите музыку в YouTube Music / браузере / приложении с медиасессией Windows. Обложка, название, исполнитель, пауза, позиция и длительность читаются напрямую через Windows SMTC. Используется текущая играющая медиасессия Windows; мод не ограничен одним браузером.

Синхронные строки загружаются из **LRCLIB** по названию, исполнителю и длительности. Наличие текста в YouTube Music само по себе не гарантирует наличия LRC в LRCLIB. При отсутствии синхронного текста остаётся информация о треке; выдуманный текст не показывается. Название текущей песни и исполнитель отправляются в LRCLIB только при активном музыкальном модуле. Кэш ограничен 100 песнями, повторный запрос отсутствующего текста — не чаще раза в минуту.

Караоке подсвечивает строку по временной разметке. Движение внутри строки и деление SmartSplit интерполируются в пределах LRC-интервала: точная пословная разметка вокала не заявляется. Пауза и перемотка учитываются. World Lyrics и Dynamic Island используют общий таймлайн. Настройки доступны по ПКМ, положение и размер — через редактор HUD или перетаскивание в чате.

## Остальные возможности

- **M** — меню, **H** — переключатель HUD шахт. ЛКМ переключает модуль, ПКМ открывает его настройки. Liquid Glass можно включить/выключить для общего оформления.
- Шахты: количество, измерения, отдельные редкости для мира/Ада/Энда, ближайшие события, отображение обновившихся событий ещё 30 секунд (настраивается). КланЛайт 88/89/90 исключены, ограничения в 90 секунд нет. Плотный шрифт с тенью; таймеры выровнены справа.
- **Шахты → HWhelper** — информация о золотом спавнере/мече из `gs_* custom_data`.
- **Косметика → Cosmetic** — нимб, сферы, орбиты, следы, питомцы, Naruto-бег, локальные клоны и вороны. **J/K** — сцены клонов/воронов; клавиши переназначаются в управлении Minecraft. Эффекты остаются локальными.
- **Уведомления → Универсальный ключ** — надпись «УНИК!», звук, громкость и общий переключатель. Свои OGG Vorbis до 20 МБ выбираются через «Свои звуки» или помещаются в `config/hwhelper/sounds`.
- Главное меню Minecraft не заменяется. Сохраняется изоляция HUD/эффектов от инвентарей и сторонних экранов Lunar; дополнительные проходы размытия не создаются.

## Перенос на другой компьютер

Для установки достаточно JAR и обычных зависимостей Fabric. На новом компьютере подключите Telegram один раз через меню мода. Обычные настройки `config/hwhelper.json` и свои звуки можно переносить.

**Не переносите папку `config/hwhelper/telegram` другим людям или на другую учётную запись Windows.** В ней находятся сессия и API-данные, защищённые Windows DPAPI и ключом шифрования базы. Код/пароль входа не записываются в обычную конфигурацию. Исходники и готовый JAR не содержат личной авторизации.

Нативные DLL уже лежат в JAR и автоматически извлекаются с проверкой SHA-256 в `config/hwhelper/runtime`. Они загружаются в процесс Java, отдельные процессы не запускаются. Сетям Telegram и LRCLIB необходим интернет; автономность означает независимость от EXE/Python.

## Сборка и проверка

Java 21: `gradlew.bat build`. Gradle Wrapper 9.8.2 включён; для первой загрузки Gradle и зависимостей нужен интернет. Результат: `build/libs/HWhelper-3.1.0.jar`.

В `build` включены `snapshotRegression`, `standaloneRegression` и `anarchyRegression`: парсер сообщений, фильтры редкостей, таймеры, HUD, геометрия косметики, синхронные строки, проверка источника/возраста Telegram-сообщения, интервалы запросов и FloodWait. Новые проверки включают переходы по избранным, границы/обход списка, фильтры групп, чтение форматированного scoreboard, паузу, защиту от повторов, подтверждение и таймаут. Эти проверки не подключают аккаунт и не отправляют сообщения или игровые команды.

Дополнительная Windows-проверка: `gradlew.bat standaloneNativeProbe`. Она загружает встроенную TDLib, проверяет JSON-транспорт без авторизации/параметров сети, DPAPI на искусственных данных и чтение текущей медиасессии с обложкой. Тестовые данные остаются в `work/standalone/probe` и не включаются в архив исходников.

На Windows x64 проверены загрузка TDLib, асинхронный обмен/закрытие, DPAPI, реальные медиаданные и PNG-обложка. Переходы на реальном сервере, вход в Telegram и отображение в работающем Minecraft/Lunar не автоматизировались: они требуют пользовательской авторизации и запуска игры.

В исходниках автономной версии находятся Java, ресурсы (включая DLL), regression-проверки, Gradle Wrapper, настройки сборки и лицензии. Старый Python-мост и исходники EXE не требуются и в этот архив не включаются.

## Источники и лицензии

TDLib использует BSL-1.0; нативные сборки 1.8.69: https://github.com/ForNeVeR/tdlib.native/releases/tag/v1.8.69. Исходный проект: https://github.com/tdlib/td. JNA 5.17.0 — Apache-2.0 или LGPL-2.1-or-later, здесь распространяется по Apache-2.0; ZXing 3.5.3 и OpenSSL — Apache-2.0; zlib — Zlib. Roboto — OFL, Golden Spawner Overlay — CC0. Тексты лицензий включены в ресурсы и `licenses`.

Косметика, CsClickGui и World Lyrics адаптированы из ранее предоставленных пользователем материалов. Геометрия и native RenderPipeline сохранены; исходные GL-вызовы не используются. Отсутствовавшие в примере bloom/текстура ворона восстановлены отдельно. Полное совпадение изображения с клиентом-источником не заявляется.
